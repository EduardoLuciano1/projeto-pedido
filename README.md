### Projeto Pedido

Um pedido de namoro feito com HTML, CSS e JavaScript.

## Estrutura

```text
frontend/
	index.html              Entrada da interface
	src/
		css/                  Estilos
		js/                   JavaScript da interface
	assets/                 Imagens, icones e outros recursos
```

## Como comecar

1. Coloque sua carta em `frontend/assets/carta.png`.
2. Atualize o link do Instagram no arquivo `frontend/src/js/main.js`.
3. Abra `frontend/index.html` no navegador para validar a interface.
